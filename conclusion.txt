CONCLUSIÓN

1. ¿Qué aprendimos?

Durante el desarrollo del proyecto aprendimos a trabajar con archivos de texto en Java para generar, almacenar y procesar información relacionada con productos, vendedores y ventas. También fortalecimos el uso de estructuras de datos, métodos, ciclos, condiciones y manejo de excepciones.

El proyecto permitió comprender la importancia de organizar un programa en diferentes componentes y de aplicar buenas prácticas de programación, como el uso de nombres descriptivos, documentación mediante comentarios Javadoc y validación de la información procesada.

Además, aprendimos a generar información pseudoaleatoria de manera coherente y posteriormente utilizarla para obtener reportes organizados. También reforzamos el manejo de archivos y el uso de Git y GitHub para llevar un control de las diferentes versiones del proyecto.

2. Aplicaciones profesionales

Los conocimientos desarrollados en este proyecto pueden aplicarse en sistemas empresariales que necesiten generar, almacenar y procesar información de ventas. Por ejemplo, una empresa podría utilizar una solución similar para llevar el control de productos vendidos, vendedores, cantidades comercializadas y valores recaudados.

Este tipo de procesamiento también puede formar parte de sistemas de inventario, puntos de venta, plataformas de comercio electrónico y aplicaciones administrativas que necesiten transformar información almacenada en archivos en reportes útiles para la toma de decisiones.

De igual manera, el manejo de archivos, estructuras de datos, validaciones y generación de reportes son conocimientos que pueden utilizarse como base para desarrollar aplicaciones de mayor tamaño que posteriormente trabajen con bases de datos y otros sistemas de información.

3. Dificultades encontradas

Una de las principales dificultades fue comprender inicialmente la forma en que debía organizarse la información entre los diferentes archivos de productos, vendedores y ventas, así como establecer una relación coherente entre sus identificadores.

También fue necesario revisar el procesamiento de los archivos para evitar que los encabezados fueran interpretados como datos y para garantizar que la información pudiera convertirse correctamente a los tipos de datos necesarios.

Otra dificultad estuvo relacionada con la generación de los reportes, especialmente al momento de ordenar los vendedores según el valor total de sus ventas y los productos según la cantidad vendida, manteniendo al mismo tiempo el formato solicitado para cada archivo.

Finalmente, el trabajo con Git y GitHub permitió identificar la importancia de controlar los cambios realizados en los archivos, especialmente cuando la información de entrada se genera de manera pseudoaleatoria. Esto ayudó a comprender la necesidad de mantener coherencia entre los archivos de entrada, el procesamiento y los reportes generados.
